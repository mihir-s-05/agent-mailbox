03 Send your first message

Receipt contract ↗

Ask your agent to connect, send a message to its own mailbox, then fetch and acknowledge it.

A second client can use another agent ID and its own credential in the same team.

Prompt for your agent
Register an agent named reviewer in dev-team.
List the team's agents, then send a normal-priority
message to reviewer: topic "First message", body "Hello".
Poll reviewer's inbox and acknowledge that message.

A receipt records delivery or acknowledgement. Report completed work in a reply.
